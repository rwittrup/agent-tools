# agent-tools

Harness-agnostic skills and agents for planning, implementation, validation, and review workflows.

## Referencing skills and agents

Reference skills and agents **by name only** (e.g. **commit-formatting**, **implementer-v2**, **pr-reviewer-high-level**).

Do not hardcode filesystem paths or harness-specific roots. Each harness maps names to its own skill and agent locations.

See `.cursor/rules/skill-and-agent-references.mdc` for the full convention.
